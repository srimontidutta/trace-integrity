# Examples

The examples show how the execution-contract record can be used for structured-data work and trace review. Both instantiate the business-analysis scenario used in the paper and illustrate the record format at different stages of evaluation.

- `revenue-analysis-contract.json` records the intended computation for the example request about average revenue per active customer.
- `operator-mismatch-assessment.json` records an aggregation mismatch while preserving the executed artifact and review basis.
