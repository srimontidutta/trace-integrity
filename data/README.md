# Machine-Readable Paper Data

This directory contains machine-readable versions of tables and counts reported in the paper. The files support secondary analysis, teaching, plotting, and evaluation-tool integration.

- `trace-integrity-dimensions.csv` reproduces the seven dimensions in Table 1.
- `bird-mini-dev-results.csv` reproduces the five reported metrics for the three prompting conditions.
- `answer-trace-quadrants.csv` records the counts shown in the answer × trace figure.
- `cait-intervals.csv` records the CAIT numerators, denominators, rates, and exact 95% binomial intervals reported in the revised manuscript.
- `executable-subset.csv` records the executable-query counts and Trace Integrity Pass Rates among executable outputs.
