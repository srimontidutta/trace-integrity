# Evaluation

The files in this directory provide a compact evaluation procedure for systems that answer structured-data requests through queries, programs, or tool-mediated computations.

A typical evaluation records the request and execution contract, applies the Trace Integrity dimensions that can be assessed reliably in the environment, retains the basis for each assessment, and reports answer-level and trace-level metrics together. CAIT is meaningful only when its denominator and trace-validity procedure are reported.

The paper's proof-of-concept uses a narrower deterministic procedure than the full seven-dimensional definition. Reusers should state which dimensions are scored, which are guaranteed by the logging environment, and which remain unassessed.
